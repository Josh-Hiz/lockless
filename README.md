# Lockless

Header-only C++ library implmenting lock-free concurrent data structures.

## Features

The following lock-free concurrent data structures to be supported:

1. Binary-search tree
2. Linked-lists
3. MPMC queues
4. SPSC queues (FastQueues)
5. Stacks
6. Hashtables (Set/Map)
7. Dynamic-Arrays
